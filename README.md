# 大溪・慈湖周邊即時影像

整合慈湖、後慈湖、石門水庫、大溪橋、東眼山、康莊路、內柵與北橫周邊共 15 支現場鏡頭。

網站：https://cihu2026.github.io/liveview/

頁面會依目前選取的鏡頭位置，顯示即時溫度、體感、濕度、能見度、風向、陣風、氣壓、紫外線與未來 6 小時逐時天氣，並提供戶外值勤提醒、Google 即時車流、公路局道路通阻、氣象警特報及最近 4 處桃園市官方測速設備。

天氣採用 Open-Meteo 免費資料，每 10 分鐘自動更新；所有預報與路況仍以官方公告及現場標誌為準。

測速設備採用政府資料開放平臺資料集 25935，GitHub Actions 每小時檢查官方 CSV；只有官方清單異動時才更新網站資料。這是設備位置、方向、取締項目與速限資料，不是即時車速或壅塞流量。

影像僅供即時路況與行前參考；本站不儲存監視器畫面。
